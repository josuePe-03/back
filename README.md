# 🏥 Backend - Sistema de Incidencias de Equipos Médicos

Este proyecto es el backend de un **Sistema de Incidencias de Equipos Médicos**, desarrollado con el objetivo de centralizar y gestionar eficientemente el mantenimiento técnico de equipos médicos en clínicas y hospitales.

## 📌 Funcionalidades Principales

- 🔧 **Gestión de Equipos Médicos**  
  Registro y control de equipos médicos por compañía.

- 👥 **Gestión de Usuarios**  
  - **Superadministrador**: Crea y administra compañías dentro del sistema.  
  - **Administrador de Empresa**: Gestiona técnicos, operadores y equipos de su compañía.  
  - **Técnicos**: Atienden incidencias y generan visitas técnicas.  
  - **Operadores**: Reportan incidencias y hacen seguimiento.

- 🏢 **Control de Compañías**  
  Cada compañía maneja su propio catálogo de usuarios y equipos.

- 🛠️ **Gestión de Incidencias**  
  Permite reportar fallas de equipos, hacer seguimiento del estado de las reparaciones y asignarlas a técnicos.

- 📅 **Visitas Técnicas**  
  Registro de visitas programadas por los técnicos para atender incidencias.

## ⚙️ Tecnologías Utilizadas

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT para autenticación
- Arquitectura modular y escalable
